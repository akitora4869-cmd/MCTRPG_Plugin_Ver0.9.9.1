# TRPGCharacter

Paper 1.20.1 / Java 17 向けの CoC第6版キャラクターシートプラグインです。

## 主な機能

- `/status` で探索者シートを本として開く
- `/status give` で右クリック可能な探索者シート本を受け取る
- STR / CON / POW / DEX / APP / SIZ / INT / EDU をクリックして変更
- 能力値は `[判定]` から「能力値×5」の 1d100 判定
- HP / MP / SAN初期値 / アイデア / 幸運 / 知識を自動計算
- 現在SANをプレイヤーごとに保存し、本から変更・SANチェック・SAN減少量入力
- HP / MPも最大値と現在値を分けてプレイヤーごとに保存
- 戦闘技能を除いたCoC第6版の技能を広く収録
- 技能名・初期値・分類を `skills.yml` から変更可能
- 技能値をクリックして変更・1d100判定
- プレイヤーごとに `players.yml` へ保存
- `/roll 1d100`、`/roll 2d6` などの通常ダイス
- GitHub ActionsでJARを自動ビルド

## コマンド

- `/status` : 探索者シートを開く
- `/status give` : 探索者シート本を受け取る
- `/status reload` : config.yml / skills.yml / players.yml を再読み込み（OP）
- `/roll <XdY>` : ダイスを振る

## skills.yml の編集

例:

```yaml
skills:
  spot_hidden:
    name: "目星"
    default: 25
    category: "探索"
```

能力値式も使えます。

```yaml
  own_language:
    name: "母国語"
    default: "EDU*5"
    category: "言語"
```

独自技能を追加する場合:

```yaml
  drone:
    name: "ドローン操作"
    default: 1
    category: "技術"
```

保存後、サーバー内で `/status reload` を実行してください。

## GitHubでJARを作る

このZIPを解凍し、中身をGitHubリポジトリの**ルート**へアップロードしてください。

正しい配置:

```text
リポジトリ/
├─ .github/
│  └─ workflows/
│     └─ build.yml
├─ pom.xml
├─ README.md
└─ src/
```

GitHubの `Actions` → `Build TRPGCharacter` から実行できます。
成功後、Artifacts の `TRPGCharacter-Paper-1.20.1` からJARを取得できます。

## サーバーへの導入

1. Paper 1.20.1 / Java 17 サーバーを停止
2. JARを `plugins` フォルダへ入れる
3. サーバー起動
4. `/status` で動作確認

初回起動時に以下が生成されます。

```text
plugins/TRPGCharacter/
├─ config.yml
├─ skills.yml
└─ players.yml
```

## 注意

`SAN初期値` は `POW×5` で自動計算されます。
`現在SAN` は初回のみ `POW×5` を使用し、一度変更するとプレイヤーごとに `players.yml` へ保存されます。
本の `[判定]` から現在SANを目標値にした1d100のSANチェックもできます。

## 現在HP / MP / SAN

派生値ページでは以下のように表示されます。

```text
HP 10 / 13 [変更]
MP 8 / 12  [変更]
SAN初期値 60
現在SAN 52 [変更] [判定] [減少]
```

`[減少]` を押して `3` と入力すると、現在SANから3を引いて保存します。
0未満にはなりません。

## HPダメージ・回復 / MP消費・回復

本の派生値ページから操作できます。

```text
HP 10 / 13 [変更] [-] [+]
MP  8 / 12 [変更] [-] [+]
```

- HP `[-]`: 入力した値だけ現在HPを減らします（最低0）
- HP `[+]`: 入力した値だけ現在HPを回復します（最大HPまで）
- MP `[-]`: 入力した値だけ現在MPを消費します（最低0）
- MP `[+]`: 入力した値だけ現在MPを回復します（最大MPまで）

## CoC第6版 能力値一括生成

本の基本能力値ページに `[能力値一括生成]` ボタンがあります。
`/status random` でも実行できます。

使用式:

```text
STR 3d6
CON 3d6
POW 3d6
DEX 3d6
APP 3d6
SIZ 2d6+6
INT 2d6+6
EDU 3d6+3
```

生成後、現在HP・現在MP・現在SANは新しい能力値から計算した最大値へ初期化されます。


## 能力値一括生成の確認

探索者シートの `[能力値一括生成]` を押しても、すぐには上書きされません。

確認画面で以下を選びます。

```text
[実行]       → CoC第6版標準式で能力値を再生成
[キャンセル] → 探索者シートへ戻る
```

`[実行]` を押した場合のみ、能力値が上書きされます。


## 技能成功時のMinecraft内効果（10技能）

技能判定に成功した場合のみ、以下の効果が発生します。

```text
応急手当   → 現在HPを1d3回復
医学       → 現在HPを1d3+1回復
精神分析   → 現在SANを1d3回復
跳躍       → 15秒間ジャンプ力上昇
水泳       → 30秒間水中呼吸
登攀       → 15秒間ジャンプ補助＋低速落下
隠れる     → 10秒間透明化
忍び歩き   → 10秒間移動速度上昇
目星       → 半径16ブロック付近の生物を10秒間発光
聞き耳     → 半径24ブロック付近の生物数と最短距離を通知
```

この10技能以外は、従来どおり1d100の技能判定だけを行います。


## Minecraft本体HPとの同期

TRPGの最大HPを、そのままMinecraftの最大体力として使用します。

例:

```text
TRPG 最大HP 13
TRPG 現在HP 8
→ Minecraft 最大体力 13
→ Minecraft 現在体力 8
```

能力値がまだ未設定で最大HPが0になる場合は、即死防止のため安全HP `4` を使用します。

満腹度は常時20に固定され、空腹による影響を無効化します。

設定:

```yaml
health-sync:
  safe-hp: 4
  disable-hunger: true
```


## Minecraftダメージ → TRPG HP逆同期

Minecraft内で実際にダメージを受けた場合、ダメージ適用後の体力をTRPG側の現在HPへ反映します。

例:

```text
TRPG現在HP 10
↓
ゾンビの攻撃でMinecraft体力が7
↓
TRPG現在HPも7
↓
右側サイドバーも HP 7 / 最大HP に更新
```

Minecraft側で回復が発生した場合も、同様にTRPG現在HPへ反映します。

能力値が未設定で安全HP4を使用している間は、未設定データへ誤ってHPを書き込まないよう逆同期を行いません。


## HP / SAN低下時の危険演出

HPとSANは最大値に対する割合で3段階判定されます。

```text
50%以下
25%以下
10%以下
```

毎tickではなく、既定では約2秒ごとに状態を確認します。

### HP

```text
50%以下 → 控えめな心拍音
25%以下 → 心拍音 + 軽い視界悪化
10%以下 → 強い心拍音 + 暗転 + 移動低下
```

### SAN

```text
50%以下 → 不穏な環境音
25%以下 → 不穏な音 + 画面の歪み
10%以下 → 強い幻聴風サウンド + 強い画面の歪み + 暗転
```

`danger-effects.check-interval` で確認間隔を変更できます。


## 複合技能（段階判定）

探索者シートに「複合技能」ページを追加しています。

### 医学＋応急手当
- 両方失敗: 回復なし
- 応急手当のみ成功: HP 1d3回復
- 医学のみ成功: HP 1d3+1回復
- 両方成功: HP 2d3+1回復

### 目星＋聞き耳
- 目星のみ成功: 周囲16ブロックを短時間強調
- 聞き耳のみ成功: 周囲24ブロックの気配を通知
- 両方成功: 周囲24ブロックを長めに強調＋気配通知

### 隠れる＋忍び歩き
- 隠れるのみ成功: 10秒透明化
- 忍び歩きのみ成功: 10秒移動速度上昇
- 両方成功: 20秒透明化＋移動速度上昇

### 登攀＋跳躍
- 登攀のみ成功: 15秒ジャンプ補助＋低速落下
- 跳躍のみ成功: 15秒ジャンプ力上昇
- 両方成功: 20秒ジャンプ力上昇＋低速落下＋移動速度上昇

複合判定では、単独技能の成功時効果は二重発動しません。

## 死亡・スペクテイター・GM復活

### 死亡時
- 探索者シートは死亡地点にドロップしません
- 探索者シート以外のアイテムは通常どおり死亡地点へドロップします
- TRPG現在HPは `0` のまま保存します
- リスポーン後、自動で `SPECTATOR` になります
- 探索者シートを失っている場合は再配布します
- 死亡状態で再ログインしてもスペクテイターを維持し、即死ループを防止します

### GM復活

OPまたは `trpg.admin` 権限を持つプレイヤー:

```text
/status revive <プレイヤー名>
```

復活すると:
- 現在HPを最大HPまで回復
- Minecraft側HPを同期
- `SURVIVAL` へ戻す
- 探索者シートが無ければ再配布


## TRPG式ダメージ / damage.yml

Minecraft標準の被ダメージ量を使わず、`damage.yml` のダイス式でTRPG現在HPを減らします。

例:

```yaml
mobs:
  ZOMBIE:
    name: "ゾンビのこぶし"
    damage: "1d3"

  CREEPER:
    name: "クリーパーの爆発"
    damage: "2d6"
```

ゲーム内:

```text
[ダメージ] ゾンビのこぶし 1d3 → 2 / HP 10 → 8
```

環境ダメージも編集できます。

```yaml
environment:
  FALL:
    name: "落下"
    damage: "1d6"

  DROWNING:
    name: "溺れ"
    damage: "1d3"
```

対応式:

```text
1
1d3
1d6+2
2d6
```

満腹度によるMinecraft標準の自然回復は初期設定で無効です。

`damage.yml` を変更後:

```text
/status reload
```

で再読み込みできます。


## CoC風の固定値装甲

Minecraft防具の標準防御計算ではなく、TRPGダメージから固定値を差し引く「装甲」として扱います。

一式装備時の既定値:

```text
革           装甲1
金           装甲1
チェーン     装甲2
鉄           装甲2
ダイヤ       装甲3
ネザライト   装甲4
```

例:

```text
ゾンビのこぶし 1d3 → 3
装甲 2
最終ダメージ 1
HP 10 → 9
```

混成装備にも対応しています。`armor.yml` の一式相当値と部位寄与率から現在装甲を算出します。

`damage.yml` の各攻撃には `armor: true/false` を設定できます。

```yaml
mobs:
  ZOMBIE:
    name: "ゾンビのこぶし"
    damage: "1d3"
    armor: true

environment:
  DROWNING:
    name: "溺れ"
    damage: "1d3"
    armor: false
```

毒・溺れ・窒息・炎上などは既定で装甲を無視します。
爆発・落下物・接触など一部の物理的環境ダメージには装甲が適用されます。

変更後は `/status reload` で `damage.yml` と `armor.yml` を再読み込みできます。

防具を着脱すると、サイドバーの定期更新時に装甲値も更新されます。

死亡状態（現在HP 0）またはスペクテイターモード中は、
心拍音・暗転・吐き気などのHP/SAN低下演出を停止します。

## KP権限

管理者(OPまたはtrpg.admin):

```text
/kp <プレイヤー名>
```

対象へKP権限を永続付与し、KPブックを渡します。

KP本人:

```text
/kpbook
```

KPブックには主要コマンドと、現在オンライン中の探索者の
キャラクター名 / PL名 / HP / MP / SAN / 装甲 / ゲームモードを表示します。

KPブックは右クリックまたは `[参加者を更新]` で再生成されるため、
その時点の最新ステータスを確認できます。

現段階では「セッション参加者」はオンライン中かつKPではないプレイヤーです。


## セッション参加者登録

探索者は自分でセッションへ参加登録します。

```text
/session join
```

退出:

```text
/session leave
```

KPまたは管理者は:

```text
/session list
```

で現在オンライン中の登録参加者を確認できます。

参加状態はUUID単位で `session.yml` に保存されるため、再ログインしても参加状態は維持されます。

KPブックの「参加探索者」ページには、
**オンライン中かつ `/session join` 済みの探索者だけ**が表示されます。

KPは探索者参加者として `/session join` できません。


## 継続ダメージの無敵時間

炎上・毒・ウィザー・溺れなどの継続ダメージには、原因ごとに個別クールタイムを設定できます。

既定値:

```text
炎上(FIRE_TICK)      3秒
毒(POISON)           5秒
ウィザー(WITHER)     4秒
溺れ(DROWNING)       5秒
窒息(SUFFOCATION)    4秒
凍結(FREEZE)         4秒
熱い床(HOT_FLOOR)    3秒
溶岩(LAVA)           3秒
```

例:

```yaml
environment:
  FIRE_TICK:
    name: "炎上"
    damage: "1"
    armor: false
    cooldown-seconds: 3
```

同じ継続ダメージを連続で受けても、クールタイム中は追加ダメージを受けません。

種類ごとに別管理なので、毒のクールタイム中に炎上した場合は炎上ダメージは通常どおり発生します。

通常のゾンビ攻撃・矢などにはクールタイムを適用しません。


## 落下距離によるTRPG式ダメージ

落下ダメージは実際の落下距離に応じて `damage.yml` からダイス式を選択します。

既定値:

```text
0～3ブロック    0
4～6ブロック    1d3
7～10ブロック   1d6
11～15ブロック  2d6
16～20ブロック  3d6
21ブロック以上  4d6
```

例:

```text
[ダメージ] 落下 (12.4ブロック) 2d6 → 7 / 装甲無効 / 最終 7 / HP 11 → 4
```

`damage.yml` の `environment.FALL.distance` を編集すれば、
距離区分やダイス式を変更できます。

落下は既定で `armor: false` のため、防具の装甲値では軽減しません。

## ダイスロール効果音

すべてのダイス判定で約1秒間の「コロコロ」演出音を鳴らし、
最後に決定音とともに結果を表示します。

対象:
- `/roll`
- 能力値判定
- 技能判定
- 複合技能判定

音はロールしたプレイヤーを中心に約12ブロック以内のプレイヤーにも聞こえます。
Minecraft標準サウンドのみを使用するため、リソースパックは不要です。


## 精神分析の対象変更

精神分析の技能判定に成功した場合、使用者自身ではなく
**5ブロック以内にいる最も近い他プレイヤー**のSANを `1d3` 回復します。

- 自分自身は対象になりません。
- 5ブロック以内に他プレイヤーがいない場合、成功してもSAN回復は発生しません。
- 対象者と精神分析を行ったプレイヤーの双方に結果を表示します。


## PL会議用 時間停止

KP / OP / `trpg.admin` 権限者は:

```text
/stop time
```

で時間停止を切り替えます。

停止中:
- 昼夜サイクル停止
- PLの移動停止
- PLのアイテム使用停止
- ブロック破壊/設置停止
- 攻撃・被ダメージ停止
- 継続ダメージ停止
- HP/SAN危険演出停止
- Mob AI停止

KP / OP / 管理者は停止中も移動・操作できます。

再度 `/stop time` を実行すると時間を再開し、
停止前のMob AI状態を復元します。


## /stop time コマンド競合修正

Minecraft/Paper標準の `/stop` はサーバー停止コマンドのため、
通常の plugin.yml コマンド登録では競合します。

この版では `/stop time` をコマンド実行前イベントで検知して横取りし、
サーバー停止コマンドには渡さない方式へ変更しています。

```text
/stop time
```

のみTRPGの時間停止として処理されます。

通常の `/stop` 単体は、従来どおりMinecraft/Paperのサーバー停止コマンドです。


## players.yml 全初期化

OPまたは `trpg.admin`:

```text
/reset players
```

誤操作防止のため、最初の実行では警告だけを表示します。
15秒以内にもう一度 `/reset players` を実行すると、
`players.yml` の `players:` 配下にある探索者情報を全員分初期化します。

`session.yml` と `keepers.yml` は変更しません。

## 炎上クールタイム修正

Minecraftでは炎によるダメージが `FIRE` と `FIRE_TICK` の両方で発生するため、
以前の `FIRE_TICK` だけのクールタイムでは連続ダメージを防ぎ切れない場合がありました。

この版では `FIRE` と `FIRE_TICK` を同じ `BURN` クールタイムとして扱い、
既定で3秒間、次の炎上系ダメージを無効化します。

```yaml
FIRE:
  cooldown-seconds: 3

FIRE_TICK:
  cooldown-seconds: 3
```

そのアーマースタンドを右クリックすると、`clues.yml` の情報を本人だけに表示します。


## アーマースタンド一括制御

KP / OP / 管理者は周囲のアーマースタンドを一括制御できます。

```text
/clue hide 20
```

半径20ブロック以内のアーマースタンドを透明化します。

```text
/clue show 20
```

再表示します。

```text
/clue protect 20
```

破壊不能にします。攻撃や爆発などによる破壊を防止します。

```text
/clue unprotect 20
```

保護を解除します。

```text
/clue setup 20
```

透明化＋破壊不能を一括で設定します。

透明化・保護状態はアーマースタンドのPersistentDataContainerに保存されるため、
サーバー再起動後も維持されます。

透明化された情報ポイントでも、目星成功時の白色パーティクルと右クリック情報取得は機能します。


## 1卓制セッション管理

サーバー内で同時に1つだけセッションを開催できます。

```text
/create session <セッション名>
```

KP / OP / `trpg.admin` 権限者がセッションを作成します。
すでにセッションが開催中の場合、2卓目は作成できません。

```text
/session join
/session leave
/session list
/session end
```

- `join`: PLが現在のセッションへ参加
- `leave`: PLが退出
- `list`: KP/管理者が参加者を確認
- `end`: セッションを終了し、ログを自動保存

`/session end` では探索者データを削除しません。
参加登録のみ終了し、ログは次のフォルダに保存されます。

```text
plugins/TRPGCharacter/session-logs/
```

ログにはセッション名、開始/終了時刻、作成者、終了者、参加履歴、
終了時にオンラインだった探索者のキャラクター名・HP・MP・SAN、
CREATE/JOIN/LEAVE/END のイベント履歴が記録されます。

開催中情報は `session.yml` に保存されるため、サーバー再起動後も維持されます。


## CoC6 判定段階

能力値判定・技能判定・複合技能判定で、1d100の出目を次の段階に分類します。

```text
01～05          クリティカル
技能値の1/5以下 スペシャル
技能値以下      成功
技能値超過      失敗
96～100         ファンブル
```

判定の優先順位はクリティカル → ファンブル → スペシャル → 成功 → 失敗です。
クリティカル、スペシャル、成功、失敗、ファンブルにはそれぞれ異なる結果音があります。

## BossBar式セッション時計

セッションは時間帯を指定して作成します。

```text
/create session 悪霊の家 夜
```

時間帯:

```text
早朝 / 朝 / 昼 / 夕方 / 夜 / 深夜
```

セッション中は全ワールドのMinecraft時刻がシナリオ時刻に連動し、
`doDaylightCycle` は停止されます。BossBarにはセッション名・時間帯・時刻・進行状態を表示します。

```text
/session time 夜
/session time start
/session time pause
/session time resume
/session time speed 60
/session time add 30
```

`speed N` は「現実1分につきゲーム内N分」の意味です。
初期値は1です。セッション作成直後の時計は停止しています。

`/session time add 30` はシナリオ時刻を30分進めます。
負数を指定すると戻すこともできます。

BossBarはセッション参加PL、KP、OP、`trpg.admin` に表示されます。

`/stop time` 実行中はセッション時計の自動進行も停止し、
解除後はセッション時刻固定が再適用されます。

`/session end` でBossBarを消し、全ワールドの通常の昼夜サイクルを再開します。
終了ログには最終時間帯・最終シナリオ時刻・時計速度も保存されます。


## TRPG武器攻撃判定

プレイヤーの素手・Minecraftの剣による攻撃をTRPG技能判定に置き換えます。

処理順:

```text
攻撃
→ 武器に対応する技能で1d100
→ クリティカル / スペシャル / 成功 / 失敗 / ファンブル
→ 成功時だけ武器ダメージをロール
→ STR+SIZによるDB
→ 対プレイヤーの場合は装甲軽減
→ HPへ反映
```

標準技能:

```text
こぶし 初期値50
刀剣   初期値20
```

標準武器:

```text
素手             こぶし 1d3+DB
木の剣           刀剣   1d4+DB
石の剣           刀剣   1d6+DB
鉄の剣           刀剣   1d8+1+DB
金の剣           刀剣   1d8+1+DB
ダイヤモンドの剣 刀剣   1d8+1+DB
ネザライトの剣   刀剣   1d8+1+DB
```

`weapons.yml` を編集すると、武器ごとの技能・ダメージ・DB有無を変更できます。
未登録アイテムは従来のMinecraft攻撃として処理されます。

### 判定段階とダメージ

```text
クリティカル  武器ダイス最大値＋DB最大値
スペシャル    通常ダメージ＋1
成功          通常ダメージ
失敗          0ダメージ
ファンブル    0ダメージ
```

スペシャルの固定ボーナスやクリティカル最大化は `weapons.yml` で変更できます。

### DB

STR+SIZから以下のDBを自動計算します。

```text
2～12   -1d6
13～16  -1d4
17～24  なし
25～32  +1d4
33～40  +1d6
41～56  +2d6
以後16増えるごとに +1d6
```


## マーシャルアーツ自動判定

近接攻撃を行うと、武器の通常命中技能とは別に「マーシャルアーツ」を自動で1d100判定します。

標準値:

```text
マーシャルアーツ 初期値 1
```

「マーシャルアーツ」は戦闘カテゴリに表示され、探索者シートから他の技能と同様に変更できます。

処理:

```text
近接攻撃
→ 通常の命中技能判定
→ マーシャルアーツ自動判定
→ 両方成功: 装甲適用前ダメージ×2
→ 命中のみ成功: 通常ダメージ
→ 命中失敗: マーシャルアーツ成功でもダメージなし
→ 装甲軽減
→ HP反映
```

倍率は `weapons.yml` の `martial-arts.damage-multiplier` で変更できます。
各武器の `martial-arts: false` を指定すると、その武器だけ自動判定対象外にできます。

既存サーバーで `skills.yml` に「こぶし」「刀剣」「マーシャルアーツ」がない場合は起動時に自動追加します。


## 敵MobのTRPGバランス

`enemies.yml` を追加し、主要MobをCoC6系の小さいHP・ダイスダメージへ調整しています。

Mobから探索者への攻撃:

```text
Mobが攻撃
→ enemies.yml の命中率で1d100
→ Critical / Special / Success / Failure / Fumble
→ 成功時に敵ダメージダイス
→ 探索者の装甲軽減
→ TRPG HPへ反映
```

探索者からMobへの攻撃:

```text
こぶし / 刀剣の命中判定
→ マーシャルアーツ判定
→ 武器ダメージ + DB
→ enemies.yml の敵装甲軽減
→ Mob HPへ反映
```

代表的な標準値:

```text
ゾンビ             HP12  命中45  1d4      装甲0
スケルトン         HP10  命中45  1d6      装甲0
クリーパー         HP10  命中100 2d6      装甲0
エンダーマン       HP16  命中55  1d6+1    装甲1
ラヴェジャー       HP24  命中60  2d6      装甲2
アイアンゴーレム   HP25  命中60  2d6      装甲3
ウィザー           HP40  命中70  2d6+2    装甲4
エンダードラゴン   HP45  命中65  2d6+2    装甲4
ウォーデン         HP35  命中70  2d6+3    装甲5
```

ボスをMinecraft標準の数百HPではなく、TRPG武器の1d3～1d8+DBで削れる範囲にし、
強さは装甲・命中率・攻撃ダイスで表現しています。

`/status reload` で `enemies.yml` と `weapons.yml` も再読み込みします。
未登録Mobは従来のMinecraft/damage.yml方式を維持します。

## CoC式落下ダメージ＋跳躍自動判定

落下ダメージはMinecraft標準値ではなく、CoC6系の方式で処理します。

```text
3ブロック以下   ダメージなし
4～6ブロック    1d6
7～9ブロック    2d6
10～12ブロック  3d6
13～15ブロック  4d6
…最大8d6
```

ダメージが発生する高さから落下すると「跳躍」を自動で1d100判定します。
成功した場合は落下ダメージダイスを1個減らします。落下ダメージは装甲無効です。

4～6ブロックの落下で跳躍成功なら `1d6 → 0d6` となり、ダメージは発生しません。
この場合は跳躍判定と軽減表示だけを行い、「落下ダメージ」表示は出しません。

また、落下以外でも最終ダメージが0ならダメージメッセージを表示しません。

設定は `damage.yml` の `environment.FALL` から変更できます。

## 自動回避・連続回避ペナルティ・決定的成功反撃

Mobまたは他の探索者からTRPG戦闘の攻撃を受け、相手の命中判定が成功した場合、
被攻撃側は自動的に「回避」を判定します。

「回避」の初期値はCoC6系に合わせて `DEX×2` です。
探索者シート上で通常の技能と同様に変更できます。

標準設定では10秒以内に回避を連続使用すると成功値が低下します。

```text
1回目: 回避そのまま
2回目: -20
3回目: -40
4回目: -60
…
最低成功値: 1
```

10秒間回避を行わなければ連続回数はリセットされます。

回避結果:

```text
成功 / Special:
  攻撃を完全回避し、ダメージ0

Critical（決定的成功）:
  攻撃を完全回避
  ＋現在メインハンドに持っている登録武器で自動反撃判定

Failure / Fumble:
  通常通り攻撃ダメージを受ける
```

自動反撃でも、その武器の「こぶし」「刀剣」等の技能値で1d100を振ります。
武器がマーシャルアーツ対象なら、反撃時もマーシャルアーツを自動判定します。
手に持っているアイテムが `weapons.yml` 未登録の場合は反撃しません。

反撃に対してさらに回避→決定的成功→反撃、という無限連鎖は起こさない仕様です。

設定は `weapons.yml` の `dodge:` から変更できます。

```yaml
dodge:
  enabled: true
  skill: "dodge"
  chain-window-seconds: 10
  penalty-per-extra-use: 20
  minimum-success-value: 1
  critical-counterattack: true
```

## 継続ダメージの無敵時間

窒息、炎上、溶岩、溺れ、毒、凍結、衰弱などは `damage.yml` の
`cooldown-seconds` に従って同一原因から連続ダメージを受けないようにしています。

スイートベリーやサボテン等の `CONTACT` にも3秒のクールタイムを追加しました。
クールタイム中にMinecraft側から同じダメージイベントが繰り返し発生しても、
TRPG HPは減少しません。

## 暗所での目星自動判定・暗視

探索者が暗い場所へ入ると、自動的に「目星」を1d100判定します。

標準ではMinecraftの明るさが `4以下` の場所を暗所として扱います。

```text
明るい場所
↓
暗所へ入る
↓
目星を自動判定
↓
成功 / Special / Critical
↓
暗視状態になる
```

成功すると、暗所にいる間は暗視効果が自動で更新されます。
明るい場所へ戻ると更新が止まり、数秒後に自然に暗視が解除されます。

失敗またはFumbleの場合、その暗所に居続けている間は再判定しません。
一度明るい場所へ戻ってから再び暗所へ入ると、もう一度目星を判定します。
これにより暗所にいるだけで判定が連続して流れることを防いでいます。

設定は `config.yml` の `dark-vision:` で変更できます。

```yaml
dark-vision:
  enabled: true
  light-level-threshold: 4
  skill: "spot_hidden"
  check-interval: 10
  effect-refresh-ticks: 80
```

`light-level-threshold` は0～15で、数値を上げるほど少し明るい場所でも目星判定が発生します。

なお、回避技能の初期値 `DEX*2` を既存サーバーの `skills.yml` に自動追加する際、
数式を数値として保存しようとして失敗する可能性があった箇所も同時に修正しました。

## 暗所の自動目星に失敗した後の再適応

暗所へ入った際の自動「目星」に失敗した場合でも、その暗所にいる間に
探索者シートから通常の「目星」判定を行い、成功すれば暗視へ適応できます。

```text
暗所へ入る
↓
自動目星 → 失敗
↓
その場で通常の「目星」を手動判定
↓
成功
↓
暗視が発動
```

手動判定で `Success / Special / Critical` のいずれかになれば暗視が発動します。
明るい場所で目星に成功しても暗視は発動しません。

すでに暗視へ適応済みの場合は、手動目星成功による重複メッセージは表示しません。

なお、自動目星そのものは従来通り「暗所への侵入1回につき1回」なので、
失敗後に何度も自動判定が流れることはありません。

## 素手攻撃の「こぶし / キック」選択

メインハンドが空の状態で敵を攻撃すると、すぐには判定せずチャットに選択肢を表示します。

```text
素手攻撃を選択: [こぶし] [キック]
```

5秒以内にどちらかをクリックすると、最初に殴った対象へ選択した技能で攻撃判定を行います。

```text
こぶし
初期値 50
ダメージ 1d3 + DB

キック
初期値 25
ダメージ 1d6 + DB
```

どちらもマーシャルアーツ自動判定の対象です。
マーシャルアーツに成功した場合は、従来通り装甲適用前ダメージへ倍率を適用します。

選択待ちの間に対象が5ブロックより離れる、対象が死亡する、武器を持つ、
または5秒を超えるとその素手攻撃はキャンセルされます。

「キック」は独立した戦闘技能として探索者シートに追加され、通常の技能と同様に技能値を変更できます。

## 素手攻撃を探索者シートで事前設定

素手攻撃は、攻撃するたびに「こぶし / キック」を選ぶ方式ではありません。

探索者シートの「戦闘設定」ページで、あらかじめ使用する素手攻撃を設定します。

```text
戦闘設定

素手攻撃
現在: こぶし

[✓ こぶし] [キック]
```

または、

```text
戦闘設定

素手攻撃
現在: キック

[こぶし] [✓ キック]
```

設定後はメインハンドが空の状態でMobや探索者を攻撃すると、
選択画面を挟まず、その場で設定済みの技能による攻撃判定を開始します。

```text
こぶし:
技能「こぶし」
1d3 + DB

キック:
技能「キック」
1d6 + DB
```

どちらもマーシャルアーツの自動判定対象です。

この設定は `players.yml` に探索者ごとに保存されるため、
ログアウトやサーバー再起動後も維持されます。

まだ一度も設定していない探索者は「こぶし」が初期選択になります。

## 基本能力値ページの配置調整

基本能力値ページは情報量が多かったため、読みやすさを優先して2ページ構成に整理しました。

```text
基本能力値 1/2

名前: 探索者名 [変更]
[能力値一括生成]

STR xx [変更] [判定]
CON xx [変更] [判定]
POW xx [変更] [判定]
DEX xx [変更] [判定]

※[判定]は能力値×5で1d100
```

続くページは次の配置です。

```text
基本能力値 2/2

APP xx [変更] [判定]
SIZ xx [変更] [判定]
INT xx [変更] [判定]
EDU xx [変更] [判定]

―― 戦闘設定 ――
素手攻撃: [✓こぶし] [キック]
こぶし:1d3+DB / キック:1d6+DB
※両方マーシャルアーツ対象
```

これにより、1ページへ能力値8種・名前・一括生成・素手設定を詰め込まず、
Minecraftの本でも各ボタンが押しやすい配置になります。

素手攻撃設定は基本能力値ページ内に残っており、独立した戦闘設定ページはありません。

## 基本能力値ページへHP・MP・SANを追加

基本能力値 2/2

APP xx [変更] [判定]

EDU xx [変更] [判定]

## 水中での自動「水泳」判定

暗所での自動目星と同じ考え方で、水中へ入ったときに一度だけ「水泳」を自動判定します。

## 技能ポイント：趣味ポイント

CoC第6版の趣味技能ポイントを実装しました。

### 計算

```text
趣味ポイント = INT × 10
```

探索者シートに「技能ポイント」ページが追加され、次の内容を確認できます。

```text
技能ポイント

趣味ポイント
合計: 140
使用: 30
残り: 110
計算: INT×10

[趣味ポイントをリセット]

職業ポイント: 未実装
```

各技能ページでは従来の `[変更]` の代わりに `[趣味+]` が表示されます。

```text
目星 45 (趣+20) [趣味+] [判定]
聞き耳 35 (趣+10) [趣味+] [判定]
```

`[趣味+]` を押すと、その技能へ何ポイント割り振るかチャット入力します。

```text
/trpgskill hobby <技能ID>
```

割り振り時は以下を自動チェックします。

- 残り趣味ポイントを超えて割り振れない
- 0以下は割り振れない
- 最終技能値は99を上限とする
- 初期技能値は消費ポイントに含めない
- 趣味ポイントは技能ごとに個別保存する

割り振った趣味ポイントだけをすべて戻したい場合:

```text
/trpgskill hobby-reset
```

リセットしても能力値、HP/MP/SAN、技能の初期値・KPによる直接設定値などは削除しません。

### 将来の職業ポイント

保存構造はあらかじめ、

```text
skill-points:
  hobby:
    allocations:
  occupation:
    allocations:
```

のように趣味・職業を分離しています。

最終技能値は、

```text
技能初期値
+ 趣味ポイント割振り
+ 職業ポイント割振り（将来）
= 最終技能値
```

という構造です。

職業システム実装時には、職業ごとの対象技能と職業ポイント計算を追加し、
趣味ポイントとは別枠で割り振れるようにできます。

## 接触系継続ダメージのクールダウン修正

サボテン・スイートベリー等の `CONTACT` ダメージで、
TRPG HPが短時間に連続して減る場合がある問題を修正しました。

変更前は、最終ダメージをHPへ反映した後にクールダウンを登録していました。
変更後は、最初の有効な接触イベントを受け付けた時点でクールダウンを登録します。

標準設定:

```yaml
CONTACT:
  name: "接触（ベリー・サボテン等）"
  damage: "1d3"
  armor: true
  cooldown-seconds: 3
```

そのため、接触し続けていても原則として3秒に1回だけTRPGダメージ判定が行われます。

また、装甲によって最終ダメージが0になった場合でも、
その接触イベントから3秒間は次のCONTACTダメージを受けません。

FIRE/FIRE_TICK、LAVA、DROWNING、SUFFOCATION、POISON、WITHER等の
既存クールダウン処理も同じ「最初のイベント時点で開始」方式になり、
継続ダメージ全体の連続発生をより安定して防止します。

## アーティファクトシステム

神話的な特殊アイテムを実装するための汎用アーティファクト基盤を追加しました。

アーティファクトは通常のMinecraftアイテムとは別物です。
配布時にPDCで固有IDが保存されるため、同じ素材の通常アイテムが
アーティファクトとして誤認されることはありません。

### KP・管理者コマンド

```text
/artifact list
/artifact give <player> <id>
/artifact remove <player> <id>
```

### テスト実装: 古き印

初期アーティファクトとして `elder_sign`（古き印）を追加しています。

```text
/artifact give <player> elder_sign
```

初期設定:

```text
素材: PAPER
常時効果:
  神話生物から受ける最終ダメージ -1

右クリック効果:
  周囲8ブロックの神話生物を退ける
  SAN消費 1
  クールダウン 30秒
  効果時間 5秒
```

右クリック効果の `REPEL_MYTHOS` は、
`/mythos summon` などで神話生物として登録された個体だけを対象にします。
通常のゾンビ、ドラウンド等には作用しません。

発動時には周囲の神話生物をプレイヤーから遠ざけ、
一定時間発光させて対象を視認しやすくします。

時間停止中はPLによるアーティファクト使用も停止します。
KP・OP・管理者は時間停止中でも通常どおり操作できます。

### artifacts.yml

今後は `plugins/TRPGCharacter/artifacts.yml` に新しい項目を追加することで、
アーティファクトを増やせる構造です。

```yaml
artifacts:
  elder_sign:
    name: "古き印"
    material: PAPER
    description:
      - "名状しがたい存在を退けるための印。"

    passive:
      mythos-damage-reduction: 1

    active:
      enabled: true
      cooldown-seconds: 30
      san-cost: "1"
      effect:
        type: REPEL_MYTHOS
        range: 8.0
        duration-seconds: 5
```

SAN消費は固定値だけでなく `1d3` や `1d6+1` の形式にも対応しています。

今後、効果タイプを追加することで、
HP/MP/SAN消費、技能判定、回復、攻撃、神話生物特効、
一時的な能力強化などへ拡張できます。

## クリティカル・ファンブル時の自動技能成長

技能判定でクリティカルまたはファンブルが発生すると、
その技能について自動で成長判定を行います。

初期設定では次の方式です。

```text
1. 技能判定でクリティカルまたはファンブル
2. 自動で1d100の成長判定
3. 1d100 > 現在技能値 なら成長成功
4. 成長成功時 1d10 上昇
5. 技能値上限は99
```

例:

```text
[CoC判定] 目星 目標値:55 / 1d100:03 → クリティカル
[技能成長判定] 目星 現在値:55 / 1d100:82 → 成長成功
★ 技能成長！ 目星 55 → 62 (+7)
```

成長値は `players.yml` の `skill-growth.allocations` に
趣味ポイント・将来の職業ポイントとは別枠で保存されます。

そのため最終技能値は、

```text
技能初期値
+ 趣味ポイント
+ 職業ポイント（将来）
+ 技能成長値
= 最終技能値
```

となります。

趣味ポイントのリセットを行っても技能成長値は消えません。
探索者データ自体を `/reset pc` で初期化した場合は成長値も初期化されます。

対象には通常の技能判定のほか、
戦闘技能、マーシャルアーツ、回避、複合技能、
暗所の自動目星、水泳の自動判定、落下時の跳躍判定も含まれます。

`/roll`、能力値判定、派生判定、SAN判定、敵側の命中判定には
技能成長は発生しません。

設定:

```yaml
skill-growth:
  enabled: true
  trigger-critical: true
  trigger-fumble: true
  increase: "1d10"
  max-skill-value: 99
```

`increase` は `1d6`、`1d10+2`、固定値 `3` などへ変更できます。

## 壁キック（登攀）

壁に密着してジャンプし、短時間のうちにもう一度ジャンプ操作を行うと「登攀」判定を行います。
成功すると壁から離れる方向＋上方向へ跳びます。スペシャル/クリティカルでは跳躍力が上がり、
ファンブルでは体勢を崩して下方向へ押し戻されます。発動後は短いクールダウンがあります。
地上での通常ジャンプ連打では発動せず、壁の近くにいる時だけ候補になります。
`/stop time` 中に行動できないPL、死亡中、スペクテイター、水中では使用できません。
この登攀判定のクリティカル/ファンブルは既存の技能成長システムにも接続されています。

Paper/Bukkitにはスペースキーそのものの押下イベントがないため、
ジャンプ開始と壁際での空中上向き速度変化から2回目の入力相当を検出します。


### 探索者シートの技能ボタン表示改善

技能名・技能値・趣味ポイント表示が長い場合でも `[趣味+]` と `[判定]` が
本の右端へはみ出さないよう、技能情報と操作ボタンを別行に表示します。
1ページの技能数も5件から4件へ減らし、刀剣・聞き耳・図書館などでも
クリック領域が安定して表示されるようにしています。

## 接触系の連続ダメージを0に変更

スイートベリー、サボテン、マグマブロックなど、短い間隔で何度も
ダメージイベントが発生するものはTRPG HPを減らさない仕様にしています。

既定で0ダメージになるDamageCause:
- `CONTACT`（スイートベリー、サボテン等）
- `HOT_FLOOR`（マグマブロック）

Minecraft側の通常ダメージもキャンセルされるため、これらに触れてもHPは減りません。
既存サーバーの古い `damage.yml` を使っている場合でも、この2種類は既定で0になります。
対象は `damage.yml` の `zero-damage-causes` で変更できます。


### 暗視の点滅対策
暗所適応の暗視効果を短時間（従来約4秒）で継ぎ足す方式から、
十分長い60秒の効果を維持する方式へ変更しました。
Minecraftの暗視効果は残り時間が短くなると画面が点滅するため、
これにより暗所滞在中のチカチカを抑えます。
明るい場所へ出た場合は暗視を即時解除します。


### 二段ジャンプ・登攀の移動技能
従来の壁キックを廃止し、Paper/Bukkitで安定して2回目のスペース入力を取得できる `PlayerToggleFlightEvent` 方式の二段ジャンプへ変更しました。実際の飛行は開始せず、跳躍判定成功時だけ空中で追加ジャンプします。

登攀は壁に向かって移動し続けると自動で登攀判定を行い、成功すると一定時間、蜘蛛のように壁へ吸着しながら上昇できます。壁から離れる・着地する・水に入ると終了します。クリティカル/スペシャルでは登攀可能時間が延長されます。

## ドリームランド・ディメンション

Paper 1.20.1上では、安定性を優先して専用ワールド `dreamlands` を別ディメンションとして扱います。

### 睡眠による移動
- 通常世界でプレイヤーがベッドで「深い睡眠」に入った時だけ判定します。
- 初期転移率は10%です。
- `/dreamland chance <0-100>` でKP/管理者が即時変更できます。
- `0` にすると睡眠からは一切転移しません。
- `/dreamland enable off` にすると睡眠・夢のクリスタルライザーを含むドリームランド機能そのものを停止できます。
- 初期設定ではアクティブなセッションがある時だけ自動転移します。
- 転移前のワールド・座標・向きを `dreamlands.yml` に保存するため、サーバー再起動後も帰還先を保持します。

### 帰還
- ドリームランド内で再び深く眠ると、保存されている現実側の地点へ戻ります。
- KPは `/dreamland return <player>` で強制帰還できます。
- KPは `/dreamland tp <player>` で強制的にドリームランドへ送れます。

### KPコマンド
- `/dreamland status` 現在の設定を表示
- `/dreamland chance <0-100>` 睡眠転移率を変更
- `/dreamland enable <on|off>` ドリームランド機能全体をON/OFF
- `/dreamland tp <player>` 強制転移
- `/dreamland return <player>` 強制帰還

KPブックにもドリームランド専用ページを追加しています。

### 夢のクリスタルライザー
旧版の「記憶地点ワープ」からドリームランド連携へ変更しました。
右クリックするとSAN 1d3 + MP3を消費し、ドリームランドへ直接移動します。
`dreamlands.enabled: false` またはセッション必須条件を満たさない場合は発動せず、SAN/MPも消費しません。
既存サーバーの旧 `DREAM_ANCHOR` 設定は起動時に自動移行します。


## ドリームランド神話地形

ドリームランド専用ワールドを、通常のMinecraft地形ではなくクトゥルフ神話TRPG向けの幻想的な専用地形へ変更しました。

### 地形の特徴
- 黒い海と急峻な岸壁
- 不自然に隆起する山稜
- 深い裂け目
- ディープスレート、ブラックストーン、玄武岩、凝灰岩を中心とした暗い地表
- スカルク、ソウルサンド、ソウルソイルが混ざる異様な低地
- 黒曜石と泣く黒曜石でできた細長い遺構
- ワープドファンガス、キノコ、スカルク系の異様な植生
- Deep Dark、Basalt Deltas、Soul Sand Valley等のバイオーム色を利用した寒色・暗色寄りの景観
- 原点周辺だけは初回転移で落下しにくい安全な高台

専用ワールド名は新規環境では `dreamlands_mythos` です。

旧版の `dreamlands` ワールドが存在するサーバーでは、古いワールドを削除せずに `dreamlands_mythos` を新規生成して自動移行します。そのため既存ワールドを破壊しません。

この地形は外部ワールド生成プラグインに依存せず、Paper/Bukkit標準のChunkGeneratorで生成します。


## ドリームランド専用生物

ドリームランドではゾンビ、クリーパー、スケルトン、通常の動物などの通常Mobは自然発生しません。
自然発生・チャンク生成・スポナー・増援などによる通常Mob生成を遮断し、プラグインが管理するドリームランド神話生物だけを自然発生させます。

実装済みの6種:
- `nightgaunt` ナイトゴーント（Phantomベース）
- `gug` ガグ（Endermanベース）
- `moon_beast` ムーンビースト（Ravagerベース）
- `zoog` ズーグ（Silverfishベース）
- `spider_of_leng` レンの蜘蛛（Cave Spiderベース）
- `shantak` シャンタク鳥（Phantomベース）

これらは既存の神話生物システムに登録されるため、TRPG用HP・命中・ダメージ・装甲・遭遇時SANチェックが適用されます。
既存サーバーの `mythos-creatures.yml` に6種が存在しない場合は、起動・リロード時に標準設定を自動補完します。

自然スポーンはプレイヤー周囲18～34ブロックを基準に行い、近くに最大6体まで出現します。
高所ではナイトゴーント/シャンタク鳥、暗い低地ではガグ/レンの蜘蛛がやや出やすくなっています。

KPコマンド:
- `/dreamland mobs on` ドリームランド生物の自然スポーンON
- `/dreamland mobs off` ドリームランド生物の自然スポーンOFF
- `/dreamland mobs rate <0-100>` スポーン抽選率変更
- `/dreamland status` 現在のスポーン設定も表示

`/mythos summon <id>`、`/summon`、スポーンエッグ等のKP/管理者による手動演出は遮断しません。

## 青紫の異界月・常時夜

ドリームランドは `dreamlands.always-night: true` により常時夜になります。
通常世界の時間は変更しません。

リソースパックなしで、TextDisplayを3層重ねた巨大な青紫の異界月を表示します。
月は各プレイヤー専用表示で、プレイヤーが移動しても遠い空に留まるよう追従します。
通常世界へ帰還すると自動的に消えます。

設定:
- `dreamlands.moon.enabled`: 異界月のON/OFF
- `dreamlands.moon.scale`: 月の大きさ。標準18.0、範囲2～40
- `dreamlands.moon.horizontal-distance`: 横方向の距離
- `dreamlands.moon.height-offset`: 高さ
- `dreamlands.moon.update-interval-ticks`: 追従更新間隔

`/status reload` で月設定も再読込されます。
